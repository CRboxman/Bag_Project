Bag - Unity背包系统项目
一个基于Unity 2021.3开发的完整背包和装备管理系统，包含完整的UI框架、资源管理和游戏数据管理功能。

📋 项目概述
本项目是一个功能完整的背包系统演示项目，展示了现代Unity游戏开发中常用的设计模式和架构。主要实现了物品管理、装备系统、商店功能以及完整的UI交互体验。

🌟 核心功能
  背包系统
    物品拖拽交换 - 支持背包与装备栏之间的拖拽操作
    装备穿戴系统 - 完整的装备穿戴/脱下功能
    物品提示面板 - 鼠标悬停显示详细物品信息
    多类型物品支持 - 支持装备、消耗品、材料等多种物品类型
  UI框架
    分层UI管理 - Bot/Mid/Top/System四层UI管理
    异步面板加载 - 优化性能的异步UI加载机制
    统一UI控制 - 集中的UI显示/隐藏管理
    事件驱动架构 - 基于EventCenter的松耦合设计
  数据管理
    JSON数据配置 - 可配置的物品和商店数据
    数据持久化 - 玩家数据的保存和加载
    配置表驱动 - 数据与逻辑分离的设计
  资源管理
    对象池系统 - 高效的GameObject复用机制
    资源异步加载 - 优化游戏性能的资源管理
    音效管理 - 完整的音频播放控制系统

🚀 快速开始
环境要求
Unity 2021.3 或更高版本
TextMeshPro 3.0.6
LeanTween (已包含)
运行项目
  使用Unity打开项目
  打开场景 Assets/Scenes/ui框架测试场景.unity
  点击播放按钮开始体验
  核心脚本说明
    Main.cs - 游戏入口点，初始化各个管理器
    BagMgr.cs - 背包系统核心逻辑，处理物品拖拽和装备切换
    UIManager.cs - UI管理器，负责面板的显示、隐藏和层级管理
    GameDataMgr.cs - 数据管理器，处理游戏数据的读取和保存
🎮 系统特性
  设计模式应用
    单例模式 - 各类管理器使用单例确保全局唯一性
    观察者模式 - EventCenter实现组件间松耦合通信
    对象池模式 - PoolMgr提供高效的对象复用
    MVC架构 - 数据、视图、逻辑分离
  性能优化
    异步资源加载避免卡顿
    对象池减少内存分配
    UI分层管理优化渲染
    事件驱动减少Update调用
📦 第三方插件
  LeanTween - 高性能补间动画库
  TextMeshPro - 高质量文本渲染
  AssetBundles-Browser - 资源包管理工具
  Cainos Pixel Art Icon Pack - 像素风格图标资源
